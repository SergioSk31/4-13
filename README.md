# 4:13 | Todo Lo Puedo En Cristo 🕊️☀️

> *"Todo lo puedo en Cristo que me fortalece."* — Filipenses 4:13

Aplicación web de dominio propio, pureza y crecimiento espiritual construida con arquitectura ligera (HTML5, CSS3, JavaScript Vanilla).

---

## ✨ Características Principales

* ☀️ **Estética "Gloria Celestial"**: Paleta en blanco marfil luminoso y oro puro resplandeciente.
* 📐 **Diseño Horizontal en 1 Pantalla (Sin Scroll)**: Interfaz dashboard optimizada para visualización sin desplazamiento vertical.
* 🔥 **Contador de Racha (Días en Victoria)**: Medallón central con conteo de días limpios y metas progresivas.
* ⏰ **Activación de Racha a las 10:00 PM**: Mecanismo de confirmación diaria para sellar la victoria de cada jornada.
* 🛡️ **Botón de Auxilio S.O.S**: Modo de emergencia con guía de respiración 4-4-4-4, versículo de rescate y plan de escape inmediato.
* 📖 **Palabra de Hoy**: Versículo bíblico diario dinámico por día del año.
* 🤝 **Mi Compromiso**: Voto diario de fidelidad y dominio propio.
* 📋 **Hábitos y Rutina**: Checklist de disciplinas diarias.
* 👑 **Identidad en Cristo**: Afirmaciones bíblicas de fortaleza espiritual.
* 🔒 **Privacidad Total**: Todos los datos se almacenan localmente en el navegador (`localStorage`) sin depender de servidores externos.

---

## 🚀 Uso

Simplemente abre `index.html` en cualquier navegador web moderno (Chrome, Edge, Firefox, Safari).
